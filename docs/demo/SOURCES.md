# Demo ontologies

Public vocabularies rendered on the demo site (https://soheilabadifard.github.io/TTL_to_3D/),
copied here unchanged so the site builds offline and reproducibly. Each stays under its own
licence; nothing here is part of ttl3d's MIT-licensed code.

| File | Vocabulary | Fetched from | Licence |
|------|------------|--------------|---------|
| `foaf.rdf` | FOAF Vocabulary Specification 0.99 | http://xmlns.com/foaf/spec/index.rdf | Creative Commons Attribution (see http://xmlns.com/foaf/spec/) |
| `skos.rdf` | SKOS Simple Knowledge Organization System | https://www.w3.org/2009/08/skos-reference/skos.rdf | W3C Document License |
| `prov-o.ttl` | PROV-O: The PROV Ontology | https://www.w3.org/ns/prov-o | W3C Document License |
| `pizza.owl` | Pizza ontology (Stanford / Manchester) | https://protege.stanford.edu/ontologies/pizza/pizza.owl | CC BY 3.0 (stated in the file) |

The Solar System demo on the same site comes from `examples/` in this repository. All were
fetched on 2026-09-11.
